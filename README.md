# factory — Claude Software Factory plugin

A Claude Code plugin that turns any repo into a Claude-driven software factory: Trilium holds all knowledge, planning and tracking; Graphify keeps a refreshed code graph of the target repo; a local web dashboard shows workstream documents and a Kanban board with live subagent steps; and `/factory:run` is the single entry point that orchestrates the stage pipeline.
